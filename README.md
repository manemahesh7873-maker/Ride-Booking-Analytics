# Ride Booking Analytics

## Project Overview

This project analyzes ride-booking performance, customer behavior, vehicle preferences, payment methods, cancellation patterns, ride distance, booking value, and ratings using Python, SQL, and Power BI.

## Objective

The objective is to perform data cleaning and exploratory data analysis (EDA), identify meaningful booking and customer patterns, and present the results through an interactive Power BI dashboard.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL / MySQL
- Power BI
- DAX

## Project Workflow

1. Data gathering using SQL/MySQL connectivity
2. Data quality checks
3. Missing-value analysis and handling
4. Duplicate-record checks
5. Data-type validation
6. Data cleaning and transformation
7. IQR-based outlier analysis
8. Exploratory Data Analysis (EDA)
9. Statistical analysis
10. Power BI dashboard development

## Key Analysis Areas

- Booking trends
- Booking status
- Vehicle type performance
- Payment method analysis
- Ride distance
- Booking value
- Customer and driver ratings
- Cancellation and incomplete-ride patterns
- Peak booking hours
- Customer behavior

## Power BI Dashboard

The interactive dashboard provides KPIs, booking trends, vehicle-wise analysis, payment-method analysis, and interactive filters for data exploration and decision-making.

## Key Insights

- Booking patterns vary across vehicle types.
- Digital payment methods are widely used.
- Booking value generally increases with ride distance.
- Driver and customer ratings are generally high.
- Cancellation and incomplete-ride analysis helps identify operational issues.
- EDA and statistical analysis help identify booking and customer behavior patterns.
