# Ride Booking Analytics

## Project Overview
An end-to-end ride booking analytics project using Python and Power BI to understand booking performance, ride outcomes, cancellations, vehicle demand, booking value, ratings, and location-level activity.

## Dataset
The project uses the original `ncr_ride_bookings.csv` dataset. The original file is kept unchanged. Python transformations are performed in memory for analysis.

## Tools
- Python: Pandas, NumPy, Matplotlib
- Power BI: Dashboard, KPIs and interactive analysis
- GitHub: Project version control

## Analysis
- Dataset shape, data types, missing values and duplicate checks
- Booking status and completion analysis
- Customer and driver cancellation analysis
- Vehicle type demand
- Monthly booking trends
- Booking value by vehicle type
- Customer and driver ratings
- Top pickup locations
- Business KPI analysis
